# DiskCleanerPro — C 盘智能清理工具

一款**通用、智能、安全**的 Windows 磁盘清理工具（PowerShell + WinForms，橙色系界面）。
按分类勾选清理内容，覆盖系统缓存、浏览器缓存、开发工具缓存与常用软件缓存，
内置多重安全保护：默认移入回收站、被占用文件自动跳过、关键路径白名单、风险分级。

## 特性

- 橙色系 WinForms 图形界面，无需图片资源，纯代码绘制
- 清理项按 系统 / 浏览器 / 开发工具 / 常用软件 / 隐私清理 分组，勾选自由
- 风险三级（绿=绝对安全 / 黄=谨慎 / 红=需确认），高风险默认不勾选
- 默认移到回收站（可恢复），可切换永久删除
- 两层白名单保护：盘根/系统目录为受保护根（不可作为删除目标），System32/WinSxS
  等关键子树内部绝对禁止，受保护路径记日志跳过
- 自动检测：只显示机器上实际存在的清理项
- 扫描后台多线程，目录大小缓存，二次扫描秒级
- 所有列表列头可点击排序（大小列按 KB/MB/GB 单位感知的数值排序）
- 每次清理自动导出 CSV 报告（`runtime\reports\clean-*.csv`，含逐项计划/实际释放与跳过数），并写入日志可追溯

## 使用方法

双击 `启动清理工具.bat`（自动以管理员 + STA 模式运行）→ 扫描 → 勾选 → 开始清理。

- 删除模式默认"移到回收站"，误删可从回收站还原
- 不确定的项目选绿色（绝对安全）即可
- 开发工具缓存、微信/QQ 数据默认不勾选（删除后需重新下载/可能含个人数据）

## 附加功能（缓存清理页之外的 8 个页签）

- 空间分析：任意目录两级扫描（自身文件 + 含子目录总占用），双击逐层下钻，
  定位空间大头后可直接删除到回收站
- 空文件夹：级联标记空子树（空 = 自身无文件且全部子目录也空），只列出可整删的
  空树顶端；Junction/符号链接按非空处理，绝不递归进链接目标
- 系统加速：实时内存水位显示；可用原生 API 清空待机列表 / 修剪工作集（需管理员，
  失败静默降级，仅提示不中断）
- 大文件：按磁盘与最小大小（100MB ~ 1GB）后台扫描，列出名称/大小/修改时间/路径，
  右键可打开所在文件夹、复制路径或删除到回收站；自动跳过系统保留目录
- 软件占用：读取注册表中已安装软件，可后台实测安装目录实际占用；只展示，不卸载
- 重复文件：按大小 + SHA-256 检测重复文件，每组默认保留 1 个副本，其余可勾选删除
- 还原点：列出系统还原点，可删除旧还原点（保留最近 3 个，需两次确认）；
  系统还原未启用时自动降级提示，不影响其他功能
- 启动项：列出注册表与启动文件夹中的开机启动项，可将 Run 键备份为 .reg 文件；
  只展示，修改请用系统自带的任务管理器/msconfig

## 隐私清理（默认不勾选，黄级风险）

- 最近使用记录（Recent 快捷方式）、跳转列表（Jump Lists）、PowerShell 命令历史
- 只清记录不清程序；勾选后随正常清理流程执行，同样过白名单闸门与回收站模式

## 扩展：添加自定义清理项

编辑 `config\cleanup-items.json`，按以下字段添加即可：

```json
{
  "id": "app_mytool",
  "category": "app",
  "name": "某软件缓存",
  "paths": ["%LOCALAPPDATA%\\MyTool\\Cache"],
  "risk": "green",
  "defaultChecked": true,
  "method": "delete-dir"
}
```

字段说明：

- `id` 唯一标识；`category` 分组（system/browser/dev/app/privacy）；`name`/`desc` 显示文本
- `paths` 目标路径数组，支持 `%VAR%` 环境变量和 `*?` 通配符
- `risk` 风险级：green（绝对安全）/ yellow（谨慎）/ red（需确认）
- `defaultChecked` 默认是否勾选
- `method` 处理方式：delete-dir（删目录内容保留根）/ delete-file（按通配符删文件）/
  exec（执行 `execCommand` 命令）
- `detect` 自动检测（可选）：`{"type":"path-exists","value":["路径"]}` 或
  `{"type":"command-exists","value":["docker"]}`，不满足则该项不显示

## 目录结构

```
├── 启动清理工具.bat       # 双击启动
├── DiskCleaner.ps1        # 主程序
├── config\cleanup-items.json  # 自定义清理项
└── runtime\               # 运行时数据（设置/扫描缓存/日志/清理报告，不入库）
```
